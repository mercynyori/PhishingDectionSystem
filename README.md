This project is  machine Learning application implemented in  Python and it can  detect and analyze possible phishing emails . The project emphasizes the basic concepts of cybersecurity in practice that have to do with email inspection, pattern matching, and development of secure software.
This application uses TF-IDF to convert text to numerical features allowing the program to understand the inputs.
Classifies the emails as PHSHING and SAFE. PHISHING-1 SAFE-0
I also implemented Logic regression to train and teach the model patterns. Multiple emails were used to improve the detection accuarcz.
Implemented a dataset and cleaned it and used the dataset to train and test my model.improved the accuracy to 96 percent.

Features:
The application is able to detect some of the signs of phishing emails.
The application inspects the content of an email message to find suspicious keywords or phrases.
The application checks the links in the email to identify if they are trustworthy or not.
The application generates a risk report based on the email message that has undergone analysis.
The application is easy to use: impacts the interface of command line.
The application is equipped with input validation features as well as error handling.
